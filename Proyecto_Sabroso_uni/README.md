# Sabroso/Bootcamp

Sitio web de domicilios ficticios de comida típica colombiana, organizado por regiones y pensado para varios países. Es un proyecto académico de práctica.

## Qué incluye
- Inicio de sesión y recuperación de contraseña
- Catálogo de comida típica dividido por regiones
- Carrito de compras y cupones
- Panel de administración: usuarios, productos y estadísticas
- CRUD de productos en JavaScript

## Tecnologías
HTML, CSS y JavaScript. Fue diseñado para conectarse a una base de datos SQL; esa conexión no está activa en esta versión.

## Estado
Prototipo en desarrollo (interfaz y lógica del lado del cliente).
